Installation

Install Feto.js from npm.

bash 
npm install feto.js

CommonJS

javascript 
const Feto = require("feto.js");

ES Module

javascript 
import Feto from "feto.js";

Feto.create()

Create a reusable instance with default configuration.

javascript 
const api = Feto.create({
  baseURL: "https://jsonplaceholder.typicode.com",
  timeout: 10000,
  retry: 2,
  retryBackoff: "exponential",
  headers: { "X-App-Version": "1.0" }
});

const res = await api.get("/posts/1");
console.log(res.data);

Base URL

Safe URL combination with absolute URL override.

javascript 
const api = Feto.create({
  baseURL: "https://jsonplaceholder.typicode.com"
});

// Relative path => combines with baseURL
await api.get("/posts/1");
// => https://jsonplaceholder.typicode.com/posts/1

// Absolute URL => baseURL ignored
await api.get("https://httpbin.org/get");

Query Parameters

Add query parameters with automatic URL encoding.

javascript 
const res = await Feto.get("https://httpbin.org/get", {
  params: {
    page: 1,
    limit: 20,
    search: "hello world"
  }
});

console.log(res.data.args);
// => { page: "1", limit: "20", search: "hello world" }

Make a GET request.

javascript 
const response = await Feto.get(

POST

Make a POST request with JSON body.

javascript 
const response = await Feto.post(
  "https://jsonplaceholder.typicode.com/posts",
  {
    title: "Hello Feto.js",
    body: "Testing POST",
    userId: 1
  }
);

PUT

Make a PUT request to update a resource.

javascript 
const response = await Feto.put(
  "https://jsonplaceholder.typicode.com/posts/1",
  {
    id: 1,
    title: "Updated Title",
    body: "Updated body",
    userId: 1
  }
);

AbortController

Cancel a request using AbortController.

javascript 
const controller = new AbortController();

const response = await Feto.get(
  "https://jsonplaceholder.typicode.com/posts/1",
  {
    signal: controller.signal
  }
);

controller.abort();

Retry

Automatically retry failed requests with fixed or exponential backoff.

javascript 
// Fixed delay
await Feto.get(url, { retry: 3, retryDelay: 500 });

// Exponential backoff
await Feto.get(url, {
  retry: 3,
  retryDelay: 500,
  retryBackoff: "exponential"
});
// Delays: 500ms, 1000ms, 2000ms

retry: 3 means 1 initial request + up to 3 retries on failure. Use retryBackoff: "exponential" for increasing delays between retries.

Interceptors

Add request and response interceptors.

javascript 
const reqId = Feto.interceptors.request.use((config) => {
  console.log("Request:", config.method, config.url);
  return config;
});

const resId = Feto.interceptors.response.use((response) => {
  console.log("Response:", response.status);
  return response;
});

// Later, remove them:
Feto.interceptors.request.eject(reqId);
Feto.interceptors.response.eject(resId);

Cache

Cache successful GET responses in memory.

javascript 
const response = await Feto.get(
  "https://jsonplaceholder.typicode.com/posts/1",
  {
    cache: true,
    ttl: 30000
  }
);

console.log(response.fromCache);

// Cache API
Feto.cache.clear();      // Clear all entries
Feto.cache.has(key);     // Check if key exists
Feto.cache.delete(key);  // Delete specific entry

Request Deduplication

Concurrent identical GET requests share one network request.

javascript 
const results = await Promise.all([
  Feto.get("https://jsonplaceholder.typicode.com/posts/1"),
  Feto.get("https://jsonplaceholder.typicode.com/posts/1"),
  Feto.get("https://jsonplaceholder.typicode.com/posts/1")
]);
Request A ─┐
Request B ─┼──▶ One network request ──▶ Responses
Request C ─┘

FormData

Send multipart form data for file uploads.

javascript 
const form = new FormData();
form.append("name", "Feto.js");
form.append("email", "hello@example.com");

const response = await Feto.post("https://httpbin.org/post", form);

Request Duration

Every response includes timing metadata.

javascript 
const res = await Feto.get("https://jsonplaceholder.typicode.com/posts/1");
console.log(res.duration); // e.g. 243 (ms)

// Cached responses have duration: 0
const cached = await Feto.get(url, { cache: true, ttl: 60000 });
console.log(cached.duration); // 0

TypeScript

TypeScript declarations are included.

typescript 
import Feto, {
  FetoInstance,
  RequestOptions,
  Response,
  CreateOptions,
  HttpError,
  TimeoutError,
  AbortError,
  NetworkError,
  InterceptorManager,
  Auth,
  InstanceCache
} from "feto.js";

const api: FetoInstance = Feto.create({
  baseURL: "https://api.example.com"
});

const res: Response = await api.get("/users");
console.log(res.data);
